# PySide6 UI Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace praatMaar’s Tk (and Mac NSPanel pill) UI with a single-process PySide6 (Qt 6) shell — tray, splash, settings, destinations, modules, help, status-pill, Meeting Buddy dialogs/overlay — then flip so shipped builds no longer use Tk.

**Architecture:** Full rewrite on a feature branch; flip when Win (primary) works and Mac/Linux are buildable. One `QApplication` owns all UI. `host` stays the OS seam (paste/autostart/app_dir/single-instance); thin OS adapters only where Qt cannot cover no-activate. Modules stay widget-free and keep using `UiDispatch`. Pill and Meeting Buddy overlay are **separate** always-on-top top-level widgets. Linux: AppImage later (manual); tray best-effort + non-tray fallback window/menu.

**Tech Stack:** Python ≥3.10, PySide6 (Qt 6), existing Faster-Whisper / sounddevice / pynput stack, pytest + ruff, PyInstaller.

**Wayfinder decisions:** `.scratch/pyside6-migration/map.md` (cutover, fidelity, packaging, process model, research links).

**Design source:** `docs/design/canvas/praatMaar-ui.dc.html`, `docs/design/toolkit-pyside6.md`, briefs under `docs/design/`.

**Research:** `docs/research/qt-no-activate-overlay.md`, `docs/research/linux-tray-pyside6.md`.

## Global Constraints

- Toolkit: **PySide6 only** in shipped UI (ADR-0005); no mixed Tk+Qt in releases.
- Platforms: Windows + macOS + Linux in destination scope; Win is day-to-day verify; Mac/Linux AppImage manual until users exist.
- Fidelity: toolkit constraints hard → canvas leads; same structure + native fonts/chrome; sign-off = live app.
- `host.Host` protocol unchanged; Linux host adapter required before claiming Linux runs.
- `UiDispatch` remains `Callable[[Callable[[], None]], None]`; implement via `QMetaObject.invokeMethod` / queued connection to main thread.
- i18n: nl / en / de via existing `i18n`.
- Do not rewrite transcription, Local LLM, or Meeting Buddy business logic — UI surfaces only.
- Branch: never commit on `main`; work on `feat/pyside6-ui` (or continuation thereof).
- Lint/format: `ruff check` + `ruff format` before commit.

```python
# ui/theme.py
from __future__ import annotations

TOKENS: dict[str, str] = {
    "accent": "#0F6CBD",
    "accent_hover": "#0A5CA3",
    "text": "#1B1F24",
    "muted": "#5A6572",
    "muted_soft": "#8A94A0",
    "surface": "#FFFFFF",
    "page": "#F7F9FB",
    "border": "#E1E5EA",
    "danger": "#C42B1C",
    "warn": "#FDE7E9",  # replace with canvas warn if different when extracting
    "ok": "#107C10",
}


def build_qss(tokens: dict[str, str] | None = None) -> str:
    t = tokens or TOKENS
    return f"""
    QWidget {{ color: {t['text']}; font-size: 13px; }}
    QDialog, QMainWindow {{ background: {t['page']}; }}
    QPushButton#primary {{
        background: {t['accent']}; color: white; border: none;
        border-radius: 6px; padding: 6px 14px;
    }}
    QPushButton#primary:hover {{ background: {t['accent_hover']}; }}
    """


def apply_theme(app) -> None:
    app.setStyleSheet(build_qss())
```

```python
# ui/app.py
from __future__ import annotations

import sys
from PySide6.QtWidgets import QApplication
from ui.theme import apply_theme

_app: QApplication | None = None


def ensure_app(argv: list[str] | None = None) -> QApplication:
    global _app
    existing = QApplication.instance()
    if existing is not None:
        _app = existing
        return existing
    _app = QApplication(argv if argv is not None else sys.argv)
    _app.setApplicationName("praatMaar")
    _app.setOrganizationName("praatMaar")
    apply_theme(_app)
    return _app
```

```python
# ui/marshal.py
from __future__ import annotations

from collections.abc import Callable
from PySide6.QtCore import QObject, QTimer, Slot
from ui.app import ensure_app


class _Invoker(QObject):
    @Slot(object)
    def _run(self, fn: object) -> None:
        assert callable(fn)
        fn()


_invoker: _Invoker | None = None


def ui_dispatch(fn: Callable[[], None]) -> None:
    """Schedule ``fn`` on the Qt main thread (safe from worker threads)."""
    ensure_app()
    global _invoker
    if _invoker is None:
        _invoker = _Invoker()
    # QTimer.singleShot(0, ...) always posts to the thread that owns the timer's context;
    # create timer from main thread via invoke on app thread:
    QTimer.singleShot(0, _invoker, lambda: fn())
```

Prefer a proven pattern if `QTimer.singleShot` overload is awkward: use `QMetaObject.invokeMethod` with a `QObject` living on the main thread. Tests may call `ui_dispatch` only after `ensure_app()` on the main thread.
